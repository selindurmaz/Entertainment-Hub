Entertainment Hub is a responsive web application designed to help users discover movies, TV series, and anime.
The platform allows users to browse different categories, search for specific titles, and manage reviews with a built-in rating system.

Technologies Used
HTML5: Used for structuring the web pages and content.

CSS3: Implements custom properties, Flexbox, Grid layouts, and smooth transition animations.

JavaScript: Handles all logic, including DOM manipulation, search filtering, and authentication.

Google Fonts: Uses "Outfit" and "Space Mono" for a modern typographic feel.
